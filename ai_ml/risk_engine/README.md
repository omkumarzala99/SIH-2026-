# Risk Engine Subsystem

Transparent rule-based and extensible multi-variable risk scoring engine for MOIL mining operations.

## Features
- **Deterministic Domain Scoring**: Transparent weights across fleet downtime, rainfall, blasting, and extraction deficit.
- **Explainable AI**: Mathematical attribution and human-readable root cause descriptions for each risk component.
- **Severity Tiers**: `LOW`, `MEDIUM`, `HIGH`, `CRITICAL`.
- **Extensibility**: Ready to be augmented with trained Random Forest / Isolation Forest anomaly detection models.
